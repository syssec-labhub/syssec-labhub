# 秋冬学期系统安全实验课安排

本学期实验课采用 **实验 + Project** 的形式，共安排 6 次课程：前 4 次围绕安全主题开展实战实验，后 2 次用于 Final Project 的展示与验收。具体日期、教室和提交入口以课程通知为准。

## 课程内容

1. **Web 渗透 + AI 系统**
2. **内存攻防**
3. **二进制逆向**
4. **内核 / 虚拟化 / 容器攻防**
5. **Project Presentation**
6. **Project 验收**

## 说明

- 前 4 次课：每次围绕特定主题开展安全实战讲解与实验，随堂完成实验任务。
- 后 2 次课：分别进行 Final Project 的展示与验收，具体要求和时间另行通知。
- 仓库中的 Lab 1、Lab 2 和选做 Lab 3 是内核安全方向的完整实验材料；课程安排中的主题名称不等同于单个 Lab 的标题。
