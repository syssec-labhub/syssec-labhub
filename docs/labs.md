# 系统安全实验课安排

本学期实验课采用 **实验 + Project** 的形式进行，共安排 **6 次课程**。  
前 4 次课为安全相关实战内容与实验，后 2 次课用于 Final Project 的展示与验收。

---

## 课程内容

1. **Web 渗透 + AI 系统** 3.24
2. **内存攻防** 4.7
3. **二进制逆向** 4.21
4. **内核 / 虚拟化 / 容器攻防** 5.19
5. **Project Presentation**  6.2
6. **Project 验收** 6.16

---

## 说明
- 前 4 次课：每次围绕特定主题开展安全实战讲解与实验，随堂完成实验任务。  
- 后 2 次课：分别进行 Final Project 的展示与验收，具体安排另行通知。
